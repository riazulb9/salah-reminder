Salah Reminder

Location

Pick a city and the coordinates and calculation method are filled in for you. For anywhere else, type the coordinates directly. Your time zone is taken from the Windows clock, so it is already correct. Leave elevation at 0 to match published tables; raise it only if sunrise and maghrib read a few minutes late.

Appearance

Each waqt has its own image, made to match the light at that hour — dawn for Fajr, the high sun for Dhuhr, raking gold for Asr, the last of the sun for Maghrib, stars for Isha. The generated geometry is the animated star-work; it can sit over the photograph, or stand on its own.

Reminders

The prayer screen holds for the first stretch so it is not dismissed by reflex, then the “I have prayed” button appears. Set it to 0 to be able to close it at any time. Three quick presses of Esc always closes it, whatever this is set to.
